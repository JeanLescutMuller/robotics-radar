# Zürich Robotics Radar

A six-month rolling Zürich/Swiss robotics and Physical AI event discovery pipeline. **Current state: handover and specifications, not runnable software.**

For Claude Code: read [CLAUDE.md](CLAUDE.md), [complete requirements](docs/REQUIREMENTS.md), [sources](docs/SOURCES.md), [migration checklist](docs/MIGRATION.md), [historical event leads](data/historical-events.json), and [example configuration](config/config.example.yaml).

Historical event data is based on prior ChatGPT reports and **must be independently revalidated**, including reported Calendar and Todoist writes. No standalone scanner or scheduler was built in ChatGPT.

**Security:** Public repository; no credentials, private Calendar entries, Todoist exports or personal context files. Read the owner's local context instructions at runtime.
